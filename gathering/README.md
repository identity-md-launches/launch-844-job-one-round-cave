# Four trails, one hearth

Delivered `artifacts/gathering/wall.png`: PNG, 1254 × 1254 pixels, the same square
dimensions as the supplied bare cave. This is gathering mark 01; no earlier
gathering record was present. Rock, cracks, torchlight, framing and all pixels
outside the added pigment remain from the input cave.

The installed image generator produced a sparse ochre/charcoal Pepe illustration;
its white backing was removed in memory and the pigment was composited onto the
original cave. Only the final wall image was saved. Four trails converge at a
hearth below Pepe's heavy-lidded eyes and broad mouth. His hands are hidden;
there are no visible hands or handprints to count. No lettering, numbers, logos,
frames, real people, or prohibited symbols were found in visual inspection.
No unmet visual requirement was observed; visual quality is a judgment rather
than something a byte verifier certifies.

winding pigment trails meeting at a hearth, hands behind back, no text or modern
finish, white backing for compositing. Built-in installed image tool used;
no API credentials or CLI fallback.
